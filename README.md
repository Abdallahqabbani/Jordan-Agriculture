## 📖 Overview

**Jordan Agriculture** is an educational and interactive website designed to introduce visitors to agriculture in Jordan, including local crops, plants, plant diseases, irrigation methods, and modern agricultural technologies.

The project aims to present agricultural information through an accessible, visually engaging, and responsive web experience.

It combines informative content, interactive elements, and agricultural data visualizations in a multi-page website.

## ✨ Features

- **Agricultural Information:** Explore crops and plants associated with agriculture in Jordan.
- **Plant Diseases:** Learn about different plant diseases through dedicated informational sections.
- **Irrigation Systems:** Discover drip, sprinkler, surface, and subsurface irrigation methods.
- **Vertical Farming:** Explore modern agricultural approaches, including hydroponics and aeroponics.
- **Agricultural Statistics:** View agricultural information through a dedicated statistics dashboard.
- **Light & Dark Modes:** Switch between visual themes with animated gradient backgrounds.
- **Responsive Layout:** Browse the website on different screen sizes.
- **Suggestions Page:** Access a suggestion form interface for visitor feedback.
- **Organized Codebase:** HTML, CSS, and JavaScript are separated into dedicated files for easier maintenance.

## 🚀 Getting Started

### Run Locally

1. Clone the repository:

```bash
git clone https://github.com/Abdallahqabbani/Jordan-Agriculture.git
```

2. Navigate to the project directory:

```bash
cd Jordan-Agriculture
```

3. Open `index.html` in your browser, or use the **Live Server** extension in Visual Studio Code.

No installation or build process is required.

### Live Demo

Visit the deployed website:

**https://abdallahqabbani.github.io/Jordan-Agriculture/**
